# Files Directory

Эта папка содержит файлы читов, которые отправляются покупателям после подтверждения оплаты.

## Текущие файлы:
- `MC_GARENA_MOD_MENU_V5.apk` — мод-меню Free Fire v5.0

## Примечание:
APK файлы игнорируются Git (добавлены в .gitignore), чтобы не загружать их в репозиторий.
При деплое на сервер нужно вручную загрузить APK файлы в эту папку.
