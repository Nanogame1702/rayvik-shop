## ♿ Доступность (A11y)

### ARIA атрибуты
- `aria-label` для всех интерактивных элементов
- `aria-hidden="true"` для декоративных иконок
- `role="tab"` и `aria-selected` для табов
- `role="radio"` и `aria-checked` для способов оплаты
- `role="dialog"` и `aria-modal` для модального окна
- `aria-labelledby` для связи заголовка с модальным окном

### Keyboard navigation
- Добавлен `tabindex="0"` для способов оплаты
- Кнопка темы теперь настоящий `<button>` элемент

### Семантика
- Использование правильных HTML элементов (`<button>` вместо `<div>`)
- Добавлены role атрибуты для custom элементов
