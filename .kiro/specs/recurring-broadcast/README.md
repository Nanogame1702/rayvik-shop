# Автоматическая ежедневная рассылка

## 📌 Краткое описание

Добавление функционала повторяющихся рассылок в Telegram-бот Luno Shop. Позволяет администратору настроить рассылку один раз, и она будет автоматически отправляться каждый день (или по другому расписанию) в заданное время.

## 🎯 Основная цель

Автоматизировать ежедневные рассылки (например, утренние акции) без необходимости каждый раз создавать новую рассылку вручную.

## ✨ Ключевые возможности

- ✅ Создание повторяющихся рассылок (ежедневно, еженедельно, ежемесячно)
- ✅ Использование существующего конструктора сообщений (текст, кнопки, фото)
- ✅ Управление рассылками (пауза, возобновление, удаление)
- ✅ Статистика отправок
- ✅ Автоматическое создание следующей задачи после отправки
- ✅ Работа с часовыми поясами (Moscow timezone)

## 🚀 Быстрый старт

### Для администратора бота:

```
/recurring_broadcast - Создать повторяющуюся рассылку для всех
/recurring_buyers_broadcast - Создать для покупателей
/recurring_list - Список всех рассылок
/recurring_pause <id> - Приостановить рассылку
/recurring_resume <id> - Возобновить рассылку
/recurring_delete <id> - Удалить рассылку
/recurring_stats <id> - Статистика рассылки
```

## 📊 Структура данных

### Таблица `recurring_broadcasts`
Хранит шаблоны повторяющихся рассылок с расписанием.

### Таблица `recurring_send_log`
Логирует каждую отправку для статистики.

## ⏱️ Оценка реализации

**Общее время:** ~4 часа

- База данных: 30 мин
- Сервисный слой: 45 мин
- Создание рассылок: 60 мин
- Управление: 45 мин
- Планировщик: 30 мин
- Интеграция: 15 мин
- Тестирование: 30 мин

## 🔄 Как это работает

```
1. Админ создает recurring broadcast с расписанием
2. Система создает первую задачу в scheduled_broadcasts
3. Планировщик отправляет рассылку в нужное время
4. После отправки система автоматически создает следующую задачу
5. Цикл повторяется, пока рассылка активна
```

## 💡 Пример использования

**Задача:** Каждое утро в 9:00 отправлять сообщение о дневной акции

**Решение:**
1. Админ создает recurring broadcast
2. Указывает текст: "🌅 Доброе утро! Скидка 20% до 12:00!"
3. Добавляет кнопку "Открыть магазин"
4. Выбирает "Ежедневно" и время "09:00"
5. Подтверждает создание

**Результат:** Каждый день в 9:00 все пользователи получают это сообщение автоматически.

## 🔧 Технические детали

- **Язык:** Python 3.11+
- **Фреймворк:** aiogram 3.x
- **База данных:** SQLite (aiosqlite)
- **Планировщик:** Кастомный async scheduler
- **Timezone:** Europe/Moscow (с поддержкой DST)
