## 🔧 Технические детали

### Архитектура:
```
User → Handler → Service → Database
                    ↓
                Scheduler (автоматическая отправка)
                    ↓
                Service (создание следующей задачи)
```

### Хранение данных:
- `recurring_broadcasts` - шаблоны рассылок
- `recurring_send_log` - история отправок
- `scheduled_broadcasts` - запланированные задачи (существующая таблица)

### Timezone:
- Все времена хранятся в UTC
- Отображение в Moscow timezone (Europe/Moscow)
- Поддержка DST (daylight saving time)

## ⚠️ Важные моменты

1. **Первый запуск:**
   - При первом запуске бота таблицы создадутся автоматически
   - Синхронизация произойдет автоматически

2. **Время:**
   - Все времена указываются в МСК (Europe/Moscow)
   - Хранятся в UTC для корректной работы

3. **Ошибки:**
   - Если отправка не удалась, следующая задача все равно создастся
   - Ошибки логируются в recurring_send_log

4. **Производительность:**
   - Планировщик проверяет задачи каждые 30 секунд
   - Точность отправки: ±30 секунд

## 🐛 Возможные проблемы

### Проблема: Рассылка не создается
**Решение:** Проверьте логи, возможно ошибка в базе данных

### Проблема: Задача не отправляется
**Решение:** Проверьте, что планировщик запущен (должно быть в логах "Планировщик отложенных рассылок запущен успешно")

### Проблема: Следующая задача не создается
**Решение:** Проверьте логи на ошибки в `process_completed_broadcast`

### Проблема: После перезапуска рассылки не работают
**Решение:** Проверьте, что синхронизация прошла успешно (должно быть в логах "Recurring broadcasts synchronized")
