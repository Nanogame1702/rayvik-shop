# 🚀 Быстрый старт

## Запуск бота

```bash
python bot.py
```

При первом запуске автоматически:
- ✅ Создадутся таблицы `recurring_broadcasts` и `recurring_send_log`
- ✅ Синхронизируются существующие рассылки (если есть)
- ✅ Запустится планировщик

## Создание первой рассылки

### Шаг 1: Отправьте команду
```
/recurring_broadcast
```

### Шаг 2: Введите название
```
Утренняя акция
```

### Шаг 3: Введите текст
```
🌅 Доброе утро!

Специальное предложение дня:
💎 Скидка 20% на все товары до 12:00!
```

### Шаг 4: Добавьте кнопку (опционально)
Нажмите "➕ Кнопка" и отправьте:
```
Открыть магазин | https://t.me/your_bot/shop
```

### Шаг 5: Нажмите "✅ Готово"

### Шаг 6: Выберите частоту
Нажмите "📅 Ежедневно"

### Шаг 7: Введите время
```
09:00
```

### Шаг 8: Подтвердите
Нажмите "✅ Создать"

## Готово! 🎉

Рассылка создана и будет отправляться каждый день в 9:00 МСК автоматически!

## Управление рассылками

### Просмотр всех рассылок:
```
/recurring_list
```

Вы увидите список всех рассылок с кнопками управления под каждой:

### Действия с рассылкой (через кнопки):
- **👁 Просмотр** - предпросмотр сообщения
- **⏸ Пауза** - приостановить рассылку (для активных)
- **▶️ Возобновить** - возобновить рассылку (для приостановленных)
- **📊 Статистика** - детальная статистика с историей
- **🗑 Удалить** - удалить рассылку (с подтверждением)

## Тестирование

### Создайте тестовую рассылку на ближайшее время:

1. `/recurring_broadcast`
2. Название: "Тест"
3. Текст: "Тестовое сообщение"
4. Готово → Ежедневно
5. Время: **текущее время + 2 минуты** (например, если сейчас 14:30, введите 14:32)
6. Создать

Через 2 минуты проверьте:
- ✅ Сообщение пришло всем пользователям
- ✅ В `/recurring_list` обновилась статистика
- ✅ Создалась следующая задача на завтра

## Частые вопросы

**Q: Как изменить время рассылки?**
A: Пока нельзя редактировать. Удалите старую и создайте новую.

**Q: Можно ли отправлять несколько раз в день?**
A: Да, создайте несколько ежедневных рассылок с разным временем.

**Q: Что если бот был выключен во время отправки?**
A: При следующем запуске пропущенная отправка не выполнится, но создастся задача на следующую.

**Q: Как остановить все рассылки?**
A: Используйте `/recurring_list` и приостановите каждую.

**Q: Можно ли отправлять только по будням?**
A: Да, выберите "Еженедельно" и отметьте Пн-Пт.
